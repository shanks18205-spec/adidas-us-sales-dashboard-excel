# Adidas US Interactive Sales Dashboard 📊

## 📌 Overview
This project is an interactive Excel dashboard built to analyze Adidas US sales performance across different regions, products, and sales methods.

The dashboard helps users quickly understand sales trends, top-performing retailers, and distribution channels.

---

## 🚀 Key Features
- Dynamic filtering by Region, Year, and Product
- Sales trend analysis (monthly)
- Sales breakdown by region (map visualization)
- Sales distribution by method (In-store, Online, Outlet)
- Top retailers performance comparison
- Clean and user-friendly dashboard design

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Slicers for interactivity
- Data Cleaning & Transformation

---

## 📊 Insights Generated
- Identified top-performing regions and retailers
- Observed sales growth trends over time
- Compared online vs in-store vs outlet performance
- Helped in decision-making using visual analytics
